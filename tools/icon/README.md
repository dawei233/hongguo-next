# 红果 Next 图标：概念说明与生成方式

记号名：**「竖屏追剧」**（Binge-Portrait Mark）。

## 为什么选这个记号

短剧的载体是**竖屏**——9:16 竖框是短剧区别于一切横屏长视频（电视、电影、横屏流媒体）
的形式语言本身。记号三层语义：

1. **竖屏帧**（9:16 圆角竖框）＝ 短剧的载体，一眼"这是在手机上看剧"；
2. **圆端点播放三角**（底色透出）＝ 看剧这条主路径，品牌红只点亮它（§2.1"克制"）；
3. **右上探出的"下一集"帧**（brand-700/900）＝ 一集接一集的追剧链条，
   也是产品名里的 **Next**。

整体右倾 7°＝"刷短剧"的节奏感（§2.1 气质关键词：快）；白屏偏左下、
深色帧偏右上，视觉重心明确且不对称。

深色变体的语义：**夜间剧场**——屏幕变暗（on-primary `#3B0E07`），播放键亮着
（背景色透出），下一集帧泛白光。与产品"播放页恒定暗色"的 DNA 同构。

## 如何避免上一版的两个坑

| 坑 | 规避方式 |
|---|---|
| 圆角方块 + 通用符号（模板感） | 记号不是"居中塞一个三角"：竖屏帧 + 播放 + 下一集链构成一个有叙事的场景；9:16 竖屏轮廓是品类专属形状（主流视频 App 全部用横屏播放键或字母标）；7° 倾斜打破四平八稳 |
| 沿用上游 guoapp 图形（"果"意象） | 无果实/果核/种子元素；上游的深藏青底 + 珊瑚横矩形 + 白三角全部弃用；上一版被否决的"果核 Seed Mark"（红 squircle + 白三角）同样弃用；`tools/gen_icon.py` 为被否决的旧生成器，勿再运行 |

## 色令牌（DESIGN-SYSTEM-V2 §3.1.1 brand 色阶，不引入表外色）

| 元素 | 浅色变体 | 深色变体 |
|---|---|---|
| 背景（主色） | brand-600 `#D92B26` | brand-500 `#FF7A6E` |
| 竖屏帧（on-primary） | `#FFFFFF` | `#3B0E07` |
| 播放三角 | 背景色透出 | 背景色透出 |
| 下一集帧 | brand-700 `#B31F1C` | brand-900 `#FFE0DC` |
| TV banner 画布 | bg-canvas 深色 `#101114`（恒定） | 同左 |

克制原则：纯色平涂，无渐变、无彩色阴影、无描边（§2.1"不做的事"）。

## 结构与安全区

- **Android 自适应图标**：背景层满幅（`@color/ic_launcher_background` = brand-600）；
  前景层 108dp 视口，全部内容落在中心 **66dp 安全圆内（33% 安全边距）**，
  圆形/圆角方形/水滴形裁切均完整；`monochrome` 沿用同一轮廓（Android 13 主题图标）。
- **API<26 基座**：`drawable/app_icon.xml` 全出血矢量（minSdk=26 实际不命中，仅资源解析需要）。
- **桌面**：1024px 源缩至 512，圆角 22.5%，`resources/icon.png`（浅）+ `icon-dark.png`（深）；
  `build/icon.{png,ico,icns}` 同步再生（electron-builder buildResources）。
- **TV banner**：426×135（任务规格；Android 官方 spec 为 320×180dp=640×360@xhdpi，
  如启动器显示变形，改脚本内 `426x135!` 为 `640x360!` 即可），左图右文，
  文字由 wqy 字体合成（"红果"`#EFEDE8` + "Next" brand-500），缺字体时右侧保持留白。

## 生成方式

```bash
bash tools/gen_icon.sh   # 幂等；全部 PNG 去时间戳块，复跑字节一致
```

依赖 ImageMagick 7（convert/identify/composite/montage），SVG 源 → `-resize` 出全部尺寸，
每个产物经 `identify` 自检。QA 产物：`tools/icon_preview.png`（全尺寸拼板 + 48px 圆形
裁切模拟）、`tools/icon_legibility_check.png`（48px 实际尺寸 + 8 倍最近邻放大）。

## 48px 可辨识性自查

48px（mdpi）实测：竖屏轮廓、圆端点播放三角、右上"下一集"帧边、深浅两套主色全部可辨；
圆形裁切模拟（自适应可见区）下记号完整、留边均匀。
